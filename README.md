# Alex & Savannah Engagement Website

This website uses the uploaded engagement photographs as the primary design reference.

## Design

- Bent-knee proposal photograph as the full-screen focal point
- Pacific Northwest forest, champagne, ivory, cedar, and gold palette
- Large graphical photo sections
- Responsive gallery with click-to-expand lightbox
- Mobile navigation
- Accessible focus indicators and reduced-motion support

## Image directory

All website images are stored in:

`images/`

All HTML image references also use the `images/` directory.

## Website files

- `index.html`
- `assets/styles.css`
- `assets/script.js`
- `images/`

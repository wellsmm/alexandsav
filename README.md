# Alex & Savannah

Engagement announcement for Alex Wells and Savannah Mendoza.

Static website with responsive styling and a keyboard-accessible photo viewer. Original photographs remain in images/. Best-wishes submission is disabled until a delivery service is configured.

## Publishing

In repository Settings → Pages, select GitHub Actions as the build source. Set the custom domain to alexandsav.com in Pages settings; CNAME alone does not configure the custom domain for Actions deployments. Configure domain DNS to point to GitHub Pages, then enable HTTPS once the certificate is ready. Run the Publish Alex and Savannah workflow.

GitHub Pages availability for this private repository depends on the GitHub account plan. Keep the repository private unless the owner explicitly requests otherwise.
